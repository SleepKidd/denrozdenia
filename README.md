# Оля, с днём рождения! ♡

Персональный сайт-поздравление от Sleepkidd Studio.

## Что внутри

- Адаптивная композиция для телефона, планшета, ПК и 4K-экрана.
- Все 7 предоставленных фотографий без искусственного увеличения разрешения, в WebP.
- Полноэкранная галерея: кнопки, стрелки клавиатуры, свайпы, закрытие Escape.
- 6 развёрнутых поздравлений, 24 сменяемых пожелания, письмо в конверте и поздравления на 6 языках.
- Частицы, конфетти, плавное появление блоков, бегущая строка и оригинальная синтезированная мелодия по нажатию.
- Поддержка `prefers-reduced-motion`, управление с клавиатуры, отсутствие автозапуска музыки.
- Фото и шрифты хранятся локально. Нет аналитики, внешних скриптов и обязательных CDN.

В сообщении было 7 изображений, а не 8. Восьмое нужно добавить после получения исходного файла; дубликат вместо него не используется.

## Запуск

Сборка и npm-зависимости не нужны:

```sh
python3 -m http.server 8080
```

Открыть `http://localhost:8080`.

## Публикация GitHub Pages

В настройках репозитория **Settings → Pages → Build and deployment** выбрать:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

Ожидаемый адрес после успешного включения Pages: `https://sleepkidd.github.io/denrozdenia/`.
Все пути относительные и поддерживают публикацию в подпапке.

## Файлы

- `index.html` — содержимое, поздравления, галерея и диалоги.
- `style.css` — оформление, адаптивность и CSS-анимации.
- `script.js` — галерея, пожелания, эффекты, музыка.
- `assets/photos/` — пользовательские фотографии.
- `assets/fonts/`, `assets/fonts.css` — локальные Cormorant Garamond и Manrope; лицензии в каталоге шрифтов.

Фотографии предназначены для этого поздравления и не предоставляются как свободные стоковые материалы.
